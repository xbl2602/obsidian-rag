# 全库知识图谱 · 观赏型视觉重构 demo（G/H/I/J/K/L/M）

> 只出观赏型 demo，不动 `guiweb/` 生产文件。
> 预览：双击 `design-demos/graph-redesign-g-strategy.html` / `graph-redesign-h-isocity.html` /
> `graph-redesign-i-starchart.html` / `graph-redesign-j-contour.html` /
> `graph-redesign-k-pastoral.html` / `graph-redesign-l-neonrain.html` /
> `graph-redesign-m-reef.html` 即可
> （单文件、内联 CSS/JS、系统字体栈、无 CDN、无外链图、离线可看）。

> 背景：A~F 见 `graph-redesign-方案说明.md`；显存教训见 `TASK_LOG.md` 问题53。

**七套共同遵守的硬约束（与 A~F 一致并加严）：**

- 第一屏是观赏品：搜索框弱化为顶栏小入口，无检索轨道、无 Inspector。
  K/L/M 只做过滤高亮＋计数＋回车飞瞄；G/H/I/J 另有与各自美学一致的检索示范
  （下拉＋信息卡，见"G/H/I/J 检索 UI 示范"一节），搜索始终是配角。
- 规模：打开即 500 档。seeded 随机（mulberry32，种子写死）生成 ~500 条假数据，
  4 库 ×125（技术笔记 / 论文阅读 / 会议记录 / 灵感随笔，K/L/M 仅库名按题材改写，
  主题池不变），每条有标题 / 摘要 / 库 / 主题 /
  更新时间 / 块数 / 管线状态（ok 70% / partial 15% / failed 8% / pending 7%）。
  另有 50 / 150 / 500 三档密度切换（确定性抽稀，同一 id 在各档稳定出现；
  K/L/M 的 500 档为全量 500 可见）。
- 渲染：500 条全走单一 Canvas 2D；DOM 只用于顶栏 / 图例 / 状态行 / tooltip /
  搜索框 / 下拉 / 信息卡。
- LOD 铁律：500 档只出聚合地貌＋首都 / 主峰 / 星座名（标签 ≤8）；150 档加 hub；
  50 档才出更多文字。字数封顶写死在代码里。
- 密度本身变成纹理：500 档好看是因为地貌层（领地格 / 灯海 / 银河带 / 等高线 /
  田野肌理 / 霓虹楼体 / 珊瑚林）在发力，
  而不是把 500 个标签画出来。
- K/L/M 色彩铁律（用户明确嫌弃"单调立方体、黑色背景"）：禁止纯黑背景与满屏几何体堆砌；
  深色主题也用有色底（暮蓝 / 霓紫 / 深青），画面须有前景 / 中景 / 背景三层
  （天空＋远山＋地貌＋河流 / 夜空＋楼群＋街面 / 海水＋远礁＋沙床）与氛围粒子。
- 动效：单 rAF 循环；环境动效点数封顶（G ≤30 / H ≤20 / I ≤6 / J ≤8 /
  K 云4＋鸟5＋粉尘12 / L 雨70＋车6 / M 泡16＋尘12＋鱼群）；
  DPR 封顶 1.5；`prefers-reduced-motion` 下静帧（只在交互时重绘）。
- 零 `backdrop-filter`、零 `will-change`（含注释都不出现，grep 可验）；浮层一律实底。
- 库开关（至少保留一库）、深浅双主题、悬停 tooltip（路径感：标题＋库＋主题＋更新＋块＋状态）、
  拖拽平移 / 滚轮缩放 / 双击重置。

## G · 策略大地图 Strategy Map（`graph-redesign-g-strategy.html`）

**参考的美学对象：**《文明6》战略视图 ＋ Paradox 大地图（EU4/CK3 政治图）＋ 游戏小地图。
致敬的是"领土色块＋国界线＋首都星标＋行军蚁"这套语言，不抄任何具体资产，全程序化绘制。

**为什么经得起 500 条：** 500 档时视觉主体是四块领土底色＋凸包国界＋六角/方/圆/三角格纹理，
节点退化成"地貌上的驻军"，先看到的是四个国家，再看到星标首都。不存在字堆字，
因为 500 档标签硬封顶 4 个（首都＋命中）。

**库分界手法（三重，套内各库细节又不同）：**
① 领土淡底（库色 5~9%）；② 国界线型四库各异——技术实线 / 论文双线 / 会议虚线 / 灵感点线
（凸包＋Catmull-Rom 平滑，缓存 Path2D）；③ 领地格形状即纹理——六角 / 方格 / 圆点 / 三角。
另有库铭牌旗（库名＋篇数）钉在国界上方。

**LOD：** 500 档格小（r=13）密铺成地貌＋仅首都标签；150 档格放大＋hub（重镇/前哨）标签≤22；
50 档格最大＋块数>40 也出标签（≤70）。节点图标按管线状态：失败红三角 / 待处理灰圈 / 首都星标。

**环境动效：** 会议/灵感国界虚线行军蚁（lineDashOffset 蠕动）、每库 6 支巡逻队（24 点）、
首都脉冲环。静止时巡逻队是唯一的逐帧小成本（24 个 fillRect）。

**深浅 token：** 深 `--canvas #0A0C0A` / 浮层 `#101411` / 强调 `#7DE2A8`；
浅 `#EDEFE7 / #FFFFFF / #0E9F6E`；四库色深浅各一套（翡翠/天蓝/琥珀/紫）。

**改造成本与风险：** 中（约 3 天）。凸包国界可由现有库锚点包络生成；格纹理层是纯新增 canvas 层，
与现有力导向节点层正交。风险：凸包在库节点数极不均时国界过大——需按分位数裁外点；
行军蚁虚线在 WebView2 缩放下的 dash 缩放需实测。

## H · 等距城邦 Iso Polis（`graph-redesign-h-isocity.html`）

**参考的美学对象：**《纪念碑谷》式等距夜景 ＋ Mini Motorways ＋ SimCity 微缩城。
致敬"一楼即一篇、楼高即体量、窗灯即人气"，不抄任何美术资产，体块全由三面体程序生成。

**为什么经得起 500 条：** 500 档时 500 栋楼按 (wx+wy) 画家排序一次，视觉主体是四片街区灯海＋
中央河流＋街区铭牌；窗灯只点亮哈希 30%，楼体半宽收缩。节点多＝城市大，这是等距城天然的
"图标少时是地点、图标多时是地形"。

**库分界手法（四重）：** ① 街区地基菱形（库色底＋四种描边线型）；
② 中央河流分隔东西街区（第二条分界线）；③ 屋顶形态——平顶天线楼 / 尖顶书塔 /
圆顶会堂 / 高塔顶灯；④ 窗灯颜色随街区。楼高＝块数（0.6 次方压缩，防高楼刺破天）。

**LOD：** 500 档无建筑标签（只 4 街区铭牌）＋窗灯 30%；150 档 hub 标签≤20＋窗灯 60%；
50 档建筑放大＋窗灯全开＋标签≤64。河流/道路常显（街区分界不依赖标签）。

**环境动效：** 窗灯正弦闪烁（时间哈希分组，不逐帧随机）、河流虚线流动、中央河流 12 辆车流光点、
高塔顶灯呼吸。动效点 ≤20。

**深浅 token：** 深夜空 `#07090E` / 浮层 `#0C0F16` / 强调 `#8FB4FF`；
浅 `#E9EDF3 / #FFFFFF / #1D6FD1`；河流深浅各一档透明度。

**改造成本与风险：** 中高（约 4 天）。等距投影需新增布局器（现有力导向坐标映射为街区逻辑坐标），
画家排序与增量索引（新楼插序）要确定性规则。风险：500 栋 ×3 面＋窗灯是四套里逐帧 fill 最多
的，低端核显需准备"灯海降级档"（窗灯全关只留楼体，已在代码里用 winP 开关预留）。

## I · 星图星座 Star Chart（`graph-redesign-i-starchart.html`）

**参考的美学对象：**Elite Dangerous 星图 ＋ No Man's Sky 银河图 ＋ Stellaris 星系图。
致敬"星域雾＋星座连线＋星等＋航线"，与 C 星环轨道不重复：C 是同心几何轨道，
I 是自由星野＋近邻星座＋银河光带。

**为什么经得起 500 条：** 500 档时银河光带显现＋星云雾＋星尘底，星点收缩（r≈1.6~4），
星座连线（每域封顶 110 条弱线）织成"星野纹理"；标签硬封顶 8（星域名＋主星）。
星多＝星系密，这是星图题材自带的密度正当性。

**库分界手法（三重）：** ① 星域雾（库色径向渐变）；② 星点形状——实心晕星 / 十字星 /
菱形星 / 环形星；③ 星座连线颜色随域＋跨域航线（主星互连虚线，6 条，灰色以示"非本域"）。

**LOD：** 500 档银河带＋星尘全开、标签 8；150 档加 hub（≤26）；50 档星点放大＋更多标签（≤70）。
连线数与密度档无关（由全量近邻预计算＋可见过滤），切档不闪变。

**环境动效：** 45% 星正弦闪烁、每域 1 个信标脉冲环、约每 8s 一颗流星（生命 1.1s 拖尾）。
动效 ≤6 个对象，是四套里最省的。

**深浅 token：** 深空 `#04060D` / 浮层 `#0A0E18` / 强调 `#9DB8FF`；
浅 `#E8EDF6 / #FFFFFF / #1D6FD1`；雾带透明度深浅各调（浅底用更深的雾色保对比）。

**改造成本与风险：** 小～中（约 2 天）。星座连线可由现有语义近邻 Top1 退化而来（无需嵌入模型，
用已有点边即可）；星形只是节点模板替换。风险：近邻连线在脏数据下可能出现跨域长线——
用"同域＋距离上限 220"双闸门已在 demo 里写死；浅色下弱线对比需按 token 表加深。

## J · 等高线地形 Contour Atlas（`graph-redesign-j-contour.html`）

**参考的美学对象：** 地形测量图 ＋《Unknown Pleasures》式等高线艺术海报 ＋ 登山地图
（三角点＋高程注记＋分水岭＋营地灯火）。
这是四套里"密度即地貌"最字面的一套：地貌层与节点层彻底解耦。

**为什么经得起 500 条：** 等高线来自独立地形核（16 高斯峰场 → 100×64 网格 →
marching squares → 10 档等值线 → 按归属库分组缓存，实测约 3000 段），与节点数无关。
500 档时节点退化成"山上灯海"，500 档标签甚至可以是 0（只留主峰＋高程注记）；
50 档时等高线变淡、节点放大出标签。节点增减不改变地貌，天然抗脏数据。

**库分界手法（三重）：** ① 等高线颜色＋线型——实线 / 长虚线 / 短虚线 / 点线，
颜色在谷底（分水岭）自然切换；② 灰色分水岭虚线（两山谷中线）；③ 三角点主峰
（▲＋库名＋虚构高程）＋高程注记。山脊-谷地-分水岭是地理学现成的分界语言。

**LOD：** 500 档等高线全显＋标签 0（仅主峰＋高程）；150 档 hub 标签≤20；
50 档标签≤64。等高线透明度随高程递增（高处实、低处淡，自带视觉层次）。

**环境动效：** 主峰脉冲环、灯火正弦闪烁、2 团云影漂移（大椭圆半透明，最便宜的"活"法）。
动效 ≤8。

**深浅 token：** 深苔底 `#080906` / 浮层 `#0E100C` / 强调 `#D8E6A0`；
浅纸底 `#EFF0E4 / #FFFFFF / #5B7A1F`；分水岭灰深浅各一档。

**改造成本与风险：** 中（约 3 天）。地形核是纯新增模块（峰场可由库中心＋hub 块数驱动，
与现有索引数据只读衔接）；等高线层独立 canvas，节点层不动。风险：marching squares
在 WebView2 首屏计算约几毫秒可忽略，但库开关/主题切换要重走分组着色——已按库分组缓存，
切换只是换 strokeStyle；峰场 sigma 需按真实库 spread 调一次参。

## K · 田园风车 Pastoral Fields（`graph-redesign-k-pastoral.html`）

**参考的美学对象：** 吉卜力式田园（《平成狸合战》式里山＋《魔女宅急便》式欧陆村庄）＋
荷兰风车明信片。致敬的是"天空/远山/庄园/河流四层＋风车地标"这套语言，不抄任何具体资产，
云/山/肌理/小屋全程序化绘制。默认白昼主题（七套里唯一的白天开场），深色＝暮色变体，
回应"不要黑色背景"最直接的一套。

**为什么经得起 500 条：** 500 档时视觉主体是天空渐变＋两重远山＋四庄园肌理
（梯田弧线 / 牧场圆点 / 村落方格 / 果园行栽，底图缓存）＋蜿蜒河流；
节点退化成"田野上的苗点"，hub 以上才是小屋。500 档标签硬封顶 8。

**库分界手法（四重）：** ① 庄园淡底（库色椭圆）；② 篱笆线型——田埂实线 /
牧场双线 / 村落小径虚线 / 果园花篱点线；③ 地貌肌理四库各不相同（弧线/圆点/方格/行栽树）；
④ 屋顶形态——平顶仓 / 尖顶屋 / 圆顶湖屋 / 高塔果仓＋风车/湖泊点睛。

**LOD：** 500 档苗点＋仅地标标签（≤8）；150 档 hub 小屋标签≤22；50 档苗点放大＋
块数>40 出标签（≤64）。肌理层与节点数无关，切档不闪变。

**环境动效：** 4 片漂移云、5 只飞鸟、12 粒花粉、风车四叶 slow 旋转。静止时只有
云/鸟/粉尘在动，全是小成本 fill。

**深浅 token：** 浅（默认）白昼 `#8FC3EC→#CFE8C8→#A9D18E` / 浮层 `#FFFFFF` /
强调麦穗 `#B45309`；深暮色 `#2C3A5E→#E88B5A` / 浮层 `#232B45` / 强调 `#FFD166`；
四库色（田绿/天蓝/琥珀/品红）深浅各一套。

**改造成本与风险：** 中（约 3 天）。肌理层是纯新增底图缓存层，与节点层正交；
小屋只是节点模板替换。风险：椭圆庄园在库节点极不均时留白过多——需按 spread
自适应椭圆半径；浅色下苗点对比需按 token 表加深（已做）。

## L · 霓虹雨夜 Neon Rain（`graph-redesign-l-neonrain.html`）

**参考的美学对象：**《银翼杀手2049》式霓虹雨夜 ＋《赛博朋克2077》夜之城街区 ＋
蒸汽波湿街面倒影。致敬"街区霓虹色＋竖牌/横牌/圆灯/三角牌＋湿街面倒影＋雨丝"，
楼体/招牌/雨/车全程序化绘制。深色底是霓紫 `#16122B`（有色非纯黑），
另有雨昼浅色主题。

**为什么经得起 500 条：** 500 档时视觉主体是霓紫夜空＋月＋远景楼群剪影＋
12 栋霓虹描边楼体＋湿街面四色倒影；节点退化成"楼上的霓虹招牌"，招牌只比米粒大一点。
500 档标签硬封顶 8，密度感由楼体＋倒影＋雨丝承担。

**库分界手法（四重）：** ① 街区霓虹底雾（楼体描边＋街面倒影同色）；
② 招牌形状——竖牌 / 横牌 / 圆灯 / 三角牌；③ 霓虹大道分界虚线（三条分隔四街）；
④ 车道流光＋招牌闪烁分组（30% 招牌参与呼吸，与 H 窗灯同理但按街区分组）。

**LOD：** 500 档招牌小＋仅地标标签（≤8）；150 档 hub 大牌标签≤22；
50 档招牌放大＋块数>40 出标签（≤64）。楼体剪影与节点数无关。

**环境动效：** 70 丝雨（单批路径一次描边，最贵的一项也只有一次 stroke）、
6 辆街车流光、30% 招牌闪烁。雨是氛围本体，关了雨就不成立，故 reduced-motion 下
给静态雨痕（底图已含街面，静帧仍成立）。

**深浅 token：** 深霓紫 `#16122B→#3B1D5A→#8A3B6E` / 浮层 `#1C1633` / 强调霓青 `#22D3EE`；
浅雨昼 `#B9C2D8` 系 / 浮层 `#FFFFFF` / 强调 `#0E7490`；
四库霓虹（薄荷/苍蓝/琥珀/品红）深浅各一套。

**改造成本与风险：** 中高（约 4 天）。街区列布局需新增布局器（现有力导向坐标
映射为列内 y 分布）；雨丝在低端核显是逐帧 70 线段——已收敛为单 path 单 stroke，
再低可降雨量（rain 数组 length 即开关）。风险：浅色下霓虹对比弱——浅色招牌
描边加深＋文字走深色墨（已做）。

## M · 珊瑚礁 Reef Glow（`graph-redesign-m-reef.html`）

**参考的美学对象：**《深海》粒子水母 ＋ ABZÛ 式珊瑚礁 ＋ 潜水长卷（丁达尔光＋沙纹＋鱼群）。
致敬"礁区色＋珊瑚形态＋泡链边界＋鱼群巡游"，珊瑚/沙纹/贝壳/鱼全程序化绘制。
深色底是深青 `#0E3A4C→#155A72`（海水非纯黑），另有浅滩浅色主题。

**为什么经得起 500 条：** 500 档时视觉主体是海水渐变＋丁达尔光柱＋远礁剪影＋
沙床沙纹＋40 株程序珊瑚林（底图缓存，与节点数无关）；节点退化成"浮游光点"，
hub 是鱼，首都才是礁冠。500 档标签硬封顶 8。

**库分界手法（四重）：** ① 礁区淡底；② 礁界线型——藻场波线界 / 贝丘双线界 /
管礁虚线界 / 母湾泡链界（round dash 点线）；③ 珊瑚形态——分枝 / 扇贝 / 管状 / 海葵，
既是底图珊瑚林的 motif 也是节点图标语言；④ 节点形态——十字苗 / 菱形 / 环形 / 月牙
＋鱼群剪影只在深色下深色、在浅色下同步换色。

**LOD：** 500 档光点＋仅礁冠标签（≤8）；150 档鱼标签≤22；50 档光点放大＋
块数>40 出标签（≤64）。珊瑚林 40 株固定，切档不动。

**环境动效：** 16 上升气泡、12 粒浮游尘、3 束缓摆光柱、每 ~16s 一趟 5 尾鱼群剪影。
动效对象约 30，是 K/L/M 里中等的一套。

**深浅 token：** 深深青 `#0E3A4C` 系 / 浮层 `#10333F` / 强调 `#5EEAD4`；
浅浅滩 `#8FD8EA→#EFE3B8` 沙 / 浮层 `#FFFFFF` / 强调 `#0E7490`；
四库礁色（藻绿/贝蓝/管琥珀/雾紫）深浅各一套。

**改造成本与风险：** 中（约 3 天）。珊瑚林是纯新增底图缓存（峰位可由库中心＋
hub 块数驱动，与索引数据只读衔接）；浮游漂移是节点级正弦偏移，不污染坐标。
风险：泡链界（round dash 粗线）在 WebView2 缩放下点径跟随 lineWidth——
已用固定像素，未跟随缩放；鱼群巡游周期在 reduced-motion 下直接关闭（已做）。

## G/H/I/J 检索 UI 示范（已补，不另起文件）

G/H/I/J 原先的搜索只是摆设（过滤高亮＋计数＋回车飞往首个命中），现已各补一套
与其美学语言一致的完整检索体验，搜索仍是配角（无检索轨道、无 Inspector，
不破坏观赏氛围）：

- **搜索框：** 占位提示写明范围与字段（如 `⌕ 搜索 500 星 · 标题/摘要/主题`），
  右侧输入计数（`N 字`）＋结果数（`命中 M`）。
- **输入即匹配：** 160ms 防抖，跨全量 500 条做标题 / 摘要 / 主题子串匹配
  （摘要为新增 seeded 字段 `sum`，不消耗随机流，老布局零漂移）。
- **命中表达：** 命中节点描白圈（＋呼吸脉冲），其余压暗至 ~0.1；标题命中处
  下拉内 `<mark>` 高亮（走各套 `--accent`）。
- **结果下拉：** 搜索框下右对齐浮层（实底 `var(--float)`，无模糊），Top 8
  （标题＋摘要＋库徽色点＋库名），每项可点，首项高亮 `cur`。
- **信息卡：** 左下固定卡（标题 / 库＋主题 / 管线状态徽 / 摘要 / 更新＋块＋#id /
  飞瞄按钮 / Esc 提示），× 关闭；点击下拉项或回车首项 → 相机平滑飞瞄（0.6s
  easeOutCubic，各套目标坐标系不变，H 照旧飞 `bx/by`）＋弹出信息卡。
- **Esc/清空恢复全景：** Esc 或删空输入 → 清空命中＋关下拉＋关卡＋相机 `fit()`。
  库开关切换时同步刷新命中与下拉。
- H 的库徽色点为方形（呼应街区铭牌），G/I/J 为圆形；动词按题材微调
  （飞瞄此条 / 此栋 / 此星 / 此峰），其余逻辑四套同构。

## 推荐排序

1. **K · 田园风车（首选落地＋第一眼最亲切）：** 七套里唯一的白昼开场，
   色彩最丰富、环境层次最完整（天/山/庄园/河/风车/鸟），直接回应"不要黑色背景"；
   工程上肌理层是只读新增底图缓存，风险中等。适合作为默认第一屏。
2. **M · 珊瑚礁（次选，题材最独特）：** 海水题材与现有六套零重叠，珊瑚林与节点
   解耦得最干净（40 株固定）；动效中等，改造成本中等。适合与 K 双壁并存
   （陆地/海洋各一）。
3. **J · 等高线地形（次选，工程最硬）：** 地貌与节点彻底解耦仍是对"500 条"
   回答得最硬的；地形核只读新增，风险最小。缺点是气质偏静，不如 K/M 第一眼热闹。
4. **L · 霓虹雨夜（备选，氛围最浓但最贵）：** 雨夜霓虹第一眼最抓人，但雨丝是
   七套里逐帧成本最高的氛围项，低端核显需降雨量档；且与 H 同属城市隐喻，
   并存时需二选一（要彩选 L，要昼选 H）。
5. **I · 星图星座（备选，仪式感最强）：** 动效最省、改造成本最小；缺点是与 C 星环
   同属天文隐喻，并存时需二选一，且深空底色在"不要黑"的诉求下不如 K/M。
6. **G · 策略大地图（备选，最有"游戏感"）：** 国界＋首都＋巡逻队的叙事感最强；
   凸包国界在库数>4 时需扩展配色与裁外点规则，成本中等。
7. **H · 等距城邦（备选，视觉最独特但最贵）：** 一楼一篇的隐喻最直观，但逐帧 fill
   量最大，低端核显需降级档；等距投影与现有力导向坐标系差异最大，改造成本最高。
   建议作为"彩蛋视图"而非默认第一屏。
