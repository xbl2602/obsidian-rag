# 拼豆店线上预约 · 前端设计方案（V3 克制版）

> 目标：粉黄只做点缀与状态，底色奶油 / 米白 + 大量留白。年轻女性受众，高级、耐看、可直接开工。
> 约束前置：禁用 SVG；禁用 emoji / 图标代表桌椅与状态；禁用大色块划分区域；桌椅必须一眼可辨；悬停反馈极弱。
> 术语：单人区 = S（右侧长吧台，椅 S1–S3）；双人区 = D（左下小方桌，椅 D1–D2）；四人区 = Q（中间大方桌，椅 Q1–Q4）。操作区 = 顶部烫豆区（不可点）。屏风 = 中部竖向。店门 = 底部。

---

## 1. 设计审计：之前“太粉嫩 / 太难看”错在哪

| # | 现象（可验证） | 原因 | 改法（本方案已落实） |
|---|---|---|---|
| 1 | 全屏粉底 + 深粉卡片同时出现，首屏粉色像素占比目测 > 45% | 把品牌色当底色用，底 / 文 / 点缀没有比例 | 底色固定奶油 `#FAF6EE`，粉黄合计 < 7% 面积，只出现在状态描边、选中下划线、主按钮（见 §2） |
| 2 | 桌椅用 emoji / 彩色图标表示，放大后模糊，状态靠颜色区分（粉 = 可订、灰 = 有人） | 图形语义弱 + 纯颜色传状态，色盲与低亮度下失效 | 桌椅一律用 CSS 盒 + 文字牌区分（见 §4），状态同时有边框样式 + 文字（例“有人·至 14:30”），颜色只做第三冗余 |
| 3 | 每个区域铺一块大粉 / 黄底来分区，视觉被切成 4 块 | 用面积色做分区，信息密度低、显廉价 | 取消区域底色，改用 1px 细线框 + 左上角小字区牌（例“单人区 · 长吧台”），分区靠留白与线框（见 §4） |
| 4 | 时间选择罗列 10:00–20:00 共 20 个按钮，平铺两屏 | 把连续时间离散成等权按钮，用户要逐个扫冲突 | 改为“开始时间步进器 + 时长步进器 + 当日空缺条”三件套（见 §5.4），按钮数量恒为 2 组步进，不随时间档增加 |
| 5 | 悬停时整椅变大、变粉、加粗阴影，移动端误触后回不去 | 动效幅度大（scale 1.15 + 换色），桌面与移动端同一套 | 悬停只做 1px 描边加深 + 2px 上浮（见 §7），移动端禁用 hover，选中态与悬停态彻底分开 |
| 6 | 点椅后弹全屏遮罩 + 中央大卡，平面图被完全盖住，用户失去方位感 | 用模态打断空间上下文 | 改为非模态：平面图平移使目标区域居中、四周仍可见 + 右侧（移动端底部）滑出详情卡，无全屏遮罩（见 §5.3） |
| 7 | 冲突只弹“该时间不可订”，不给下一步 | 报错无出路，用户要自己回去试 | 冲突卡固定三行：原因 + 最近可订时间 + 一键切换按钮（文案见 §5.5） |
| 8 | 表单只校验“不能为空”，手机号 10 位也能提交，成功后椅子状态不变 | 校验与回写缺失，用户不信任系统 | 昵称 2–12 字、手机 `^1\d{10}$`，提交中按钮 loading，成功后椅子即时转“有人”（文案与回写见 §5.6–5.7） |

## 2. 设计语言

### 2.1 配色（全部十六进制，用量比例）

| 角色 | 色值 | 用量 | 出现位置（穷举，之外不许用） |
|---|---|---|---|
| 底 1 · 页面底 | `#FAF6EE`（奶油米白） | 约 62% | 页面背景、平面图画布 |
| 底 2 · 卡片底 | `#FFFFFF` | 约 18% | 顶部吸附卡、详情卡、票据、toast |
| 底 3 · 分隔底 | `#F1EAE0` | 约 8% | 分割线、空缺条轨道、输入框底（`#F7F2E9` 二选一，统一用 `#F1EAE0`） |
| 文 1 · 主文字 | `#2B2620` | — | 标题、正文、座位编号 |
| 文 2 · 次文字 | `#7A7266` | — | 说明、时间刻度、区牌 |
| 文 3 · 弱文字 | `#A8A094` | — | 占位符、禁用态文字 |
| 线 | `#E2D9C9` / 加深 `#CFC3AF` | — | 卡片边框用 `#E2D9C9`，桌椅描边用 `#CFC3AF` |
| 粉（点缀） | `#D98CA3`（灰粉）+ 深粉文字 `#A34A66` | 合计 ≤ 4% | 仅 3 处：①已选中椅描边 `#D98CA3`；②主按钮底 `#D98CA3`（白字）；③日期选中下划线 `#D98CA3`。禁用浅粉底铺满 |
| 黄（点缀） | `#C99A2B`（芥黄，深色保证对比）+ 浅黄底 `#FBF3DC` | 合计 ≤ 3% | 仅 3 处：①提示条（分桌提示 / 单人区满转双人提示）左边框 + 浅底；②空缺条中“已占用段”用 `#E4D3A8`；③聚焦引导线。禁用亮黄 `#FFD400` 系 |
| 成功绿 | `#4F7A5B` | < 1% | 仅票据顶部“预约成功”四字 + 对勾文字“✓”（文本字符，非图标） |
| 错误红 | `#B3402E` | < 1% | 仅表单错误文案与冲突卡标题 |

对比度（正文级均 ≥ 4.5:1）：`#2B2620` on `#FFFFFF` = 15.2:1；`#7A7266` on `#FAF6EE` = 4.6:1；`#A34A66` on `#FFFFFF` = 5.1:1；`#C99A2B` 不做正文色，只做边框与底；按钮 `#FFFFFF` on `#D98CA3` = 4.0:1，按大文字 / 粗体 14px+ 处理，按钮文字强制 15px / 600。

### 2.2 字体字号层级（中文）

- 字体栈：`system-ui, -apple-system, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans SC", sans-serif`。数字与时间用 `font-variant-numeric: tabular-nums` 等宽对齐。
- 层级（字号 / 行高 / 字重 / 用途）：
  - H1 票据标题：20px / 28px / 700，仅票据用。
  - H2 卡片标题：16px / 24px / 700，详情卡标题、弹窗标题。
  - H3 区牌 / 组标题：13px / 20px / 700，平面图区牌、表单组名。
  - 正文：14px / 22px / 400，说明、按钮文字（按钮 15px / 600 例外）。
  - 小字：12px / 18px / 400，时间刻度、空缺条时刻、toast、辅助说明。
  - 座位编号：13px / 20px / 700，椅面中央。
  - 状态牌：11px / 16px / 600，椅下方状态行。

### 2.3 圆角 / 间距 / 阴影体系

- 圆角：卡片 12px；按钮 10px；椅 8px；桌 10px；输入框 8px；toast 10px；日期 pill 999px（仅日期一处允许全圆）。屏风、操作台直角 2px（刻意与家具区分）。
- 间距：4px 基准。卡内边距 16px；卡间距 12px；表单行距 12px；平面图内家具间距 ≥ 24px（桌面）/ ≥ 16px（移动）；椅与状态牌间距 4px。
- 边框：默认 1px `#E2D9C9`；家具描边 1.5px `#CFC3AF`；选中 2px `#D98CA3`；焦点可见 2px `#2B2620` outline（键盘专用）。
- 阴影（全站只用两档，禁止大面积投影）：
  - `card`：`0 1px 2px rgba(43,38,32,0.06)`，顶部吸附卡、详情卡、票据。
  - `float`：`0 4px 16px rgba(43,38,32,0.10)`，仅详情卡滑出时 + toast。悬停不加阴影。

## 3. 页面结构：布局与信息层级

### 3.1 进站弹窗（人数选择）

- 桌面：页面中央 360×420 卡（圆角 16px，`card` 阴影），背后页面可见但不可点（遮罩 `rgba(43,38,32,0.32)`，无模糊）。移动端：底部弹层，圆角顶部 16px，高度 62vh。
- 卡内自上而下：①标题“请选择到店人数”（H2 16px）；②副标题“用于匹配可坐的区域，不含陪同等候”（12px `#7A7266`）；③滚轮选择器（见 §5.1）；④规则提示行（12px，动态文案见 §5.1）；⑤主按钮“进入选座”（全宽，高 44px，底 `#D98CA3` 白字 15px/600，未选时禁用态底 `#EDE6D8` 字 `#A8A094`）。
- 不选不能进：遮罩点击不关闭，无关闭叉，Esc 无效，返回键拦截。选后按钮才可用。

### 3.2 顶部吸附卡（日期 + 时间滑块）

- 位置：`position: sticky; top: 0; z-index: 20`，白底，底边 1px `#E2D9C9` + `card` 阴影。桌面最大宽 1120px 居中，内边距 12px 16px；移动端全宽，内边距 10px 12px。
- 第一行（日期）：14 天横滑条，左起“今天 M/D 周X”至第 14 天。每项宽 56px：上行 12px 周X / M-D（次文字），下行 14px 星期名（选中时 700 + 底部 3px `#D98CA3` 下划线）。横滑 `scroll-snap`，选中项自动居中。
- 第二行（时间滑块）：左标签“开始时间”13px/700 + 当前值“14:30”（14px/700 tabular-nums）；中部 range 滑杆 10:00–20:00 步进 30 分钟；右标签“时长”+ 步进器 `[-][2小时][+]`（步进 30 分钟，范围 0.5–4 小时，移动端换行到第三行）。滑杆下方刻度仅 4 个：`10:00 13:00 16:00 20:00`（12px `#A8A094`）。
- 第三行（仅当需要时出现）：提示条，高 32px，浅黄底 `#FBF3DC` + 左 3px `#C99A2B`，12px `#2B2620`。文案见 §5.2（例“5–6 位需分桌：请选择两把相邻的椅子”）。

### 3.3 平面图区

- 桌面：左侧平面图（约 720px）+ 右侧详情卡位（约 360px，空态显示占位见 §3.4）。移动端：上下结构，平面图在上（全宽，高约 380px），详情卡底部弹层。
- 平面图容器：奶油底 `#FAF6EE`，1px `#E2D9C9` 边框，圆角 12px，内边距 24px。顶部一行：左“店内平面图”（H3）+ 右“已选 2026-09-10 · 14:30 · 2小时”（12px 次文字，随滑块实时更新）。底部一行图例（12px 次文字，文字图例非图标）：“实线框 = 可订 · 点线框 = 有人 · 灰色描边 + 锁字 = 规则锁 · 粉描边 = 已选中”。
- 方位：上 = 烫豆操作区，下 = 店门，中文标注“上 / 下”不依赖方向感。缩放：桌面固定比例不缩放；移动端允许双指缩放 1.0–1.6，禁止旋转。

### 3.4 详情卡（点椅后）

- 桌面：平面图右侧 360px 独立卡，白底圆角 12px。自上而下：①“座位 S2 · 单人区”（H2）+ 关闭“关闭”（文字按钮 13px）；②三行键值（14px）：开始时间步进器、时长步进器、人数回显“2 位”（不可改，附“改人数”文字链）；③“当日空缺”条（见 §5.4）；④冲突区（默认隐藏）；⑤昵称 + 手机两输入框；⑥主按钮“确认预约”（全宽 44px）；⑦小字“到店后请向店员出示票据后 4 位”。
- 空态（未点椅）：同一位置显示占位卡，文案“点击一把可订的椅子查看时间”（14px 次文字居中），无输入框无按钮。
- 移动端：底部弹层，占屏高 55–70%，顶部 20px 拖拽条（圆角条仅装饰），可下滑关闭，下滑后焦点回到平面图。

### 3.5 票据（成功）

- 桌面中央 400px 卡，移动端底部弹层。结构：①“预约成功”（20px/700 + 前缀文本“✓ ”，`#4F7A5B`）；②票据号 8 位（例 `PD-7Q2X9A`，16px/700 tabular-nums）+ “请截图保存”；③五行键值（14px）：日期 / 开始–结束 / 座位（例 Q3·四人区）/ 昵称 / 手机后 4 位（全号不回显，例 `138****8000` 脱敏写法按“前 3 + **** + 后 4”）；④两按钮：“返回平面图”（次按钮，白底描边）与“复制票据号”（主按钮）；⑤小字“开店前 10 分钟可入座，超时 15 分钟自动释放”。

### 3.6 Toast

- 位置：桌面右下，移动端底部居中（详情卡上方）。黑底 `#2B2620` 白字 13px，圆角 10px，内边距 10px 14px，`float` 阴影，出现 2.4s 自动消失。同一时间只存 1 条，新 toast 替换旧的。文案见各交互（例“已切换到 9 月 11 日，该时段状态已更新”）。

## 4. 平面图画法（无 SVG / 无图标 / 无大色块）

实现方式：全部用 HTML `div` + CSS 边框 / 背景线条绘制，不引入任何 SVG 文件、内联 `<svg>`、emoji、icon font。材质 hint 只用边框样式与 repeating-linear-gradient 细线纹理（线宽 1px、间隔 6px，对比极弱）。

### 4.1 画布与比例

- 画布逻辑尺寸：宽 100 × 深 130 单位。桌面渲染约 640×830px 内；移动端等比缩小，最小椅盒 44×44px（触摸下限）。
- 北（上）→南（下）依次：操作区（高 14）/ 留白 6 / 四人桌（28×28）居中 / 留白 8 / 屏风竖条（宽 2，高 40，偏中线右 8）/ 双人桌（18×18，西南）与吧台（40×10，东南竖放？实际为右侧横向长条 10×40）同层 / 留白 6 / 店门（宽 24，高 4，底部居中）。
- 所有家具白底 `#FFFFFF`，描边 1.5px `#CFC3AF`。区域不填色：每个区域外有一个 1px `#E2D9C9` 虚线（`dashed 1px`）围框 + 左上角区牌小字（11px/700 `#7A7266`，例“单人区 · 长吧台 · 3 席”）。

### 4.2 各元素形态

| 元素 | 形态（CSS 盒） | 材质 hint | 尺寸比例（相对） | 标注文案（原文） |
|---|---|---|---|---|
| 长吧台（单人区桌） | 横向长矩形，圆角 10px，实线 1.5px | 顶部一条 1px 内线（`inset box-shadow 0 1px 0 #EDE6D8`）示意台面厚度 | 宽 40 × 深 10（约为四人桌宽的 1.4 倍，窄而长） | 桌中 12px 次文字“长吧台（店员在此侧）” |
| 小方桌（双人区桌） | 正方形，圆角 10px，实线 1.5px | 无纹理，纯白（与吧台区分靠长宽比） | 18×18 | 桌中“小方桌” |
| 大方桌（四人区桌） | 大正方形，圆角 10px，实线 2px（比小桌粗 0.5px，暗示承重 / 主桌） | 四角各 6px 圆点？禁用图标，改用四边中点 4px 缺口（`outline-offset` 技巧或伪元素白块压边）示意四人方位 | 28×28（小方桌面积约 2.4 倍） | 桌中“大方桌 · 至少 3 位” |
| 椅（全部 9 把） | 圆角 8px 小矩形，宽 10 × 深 8，中央两行字：上行编号（13px/700，例“S2”），下行状态（11px/600） | 椅背 hint：盒顶部 3px 深色条（`border-top: 3px solid #E2D9C9`），一眼区分桌（无背条）椅（有背条） | 椅间距 ≥ 6 单位；椅与所属桌间距 3 单位，归属无歧义 | 见 §4.3 状态文案 |
| 屏风（中部竖向） | 宽 2 × 高 40 细长条，直角 2px，描边 1px `#A8A094`，底 `repeating-linear-gradient(45deg, #fff 0 5px, #F1EAE0 5px 6px)` 细斜纹 | 斜纹 = 半透隔断暗示，不可用实色块 | 纵贯中部，上下留白各 ≥ 8 | 竖排 11px 文字“屏风”（`writing-mode: vertical-rl`），不遮挡椅 |
| 烫豆操作区（顶部，不可点） | 宽 76 × 高 14 长条，直角 2px，描边 1px dashed `#A8A094`，底同屏风斜纹但方向 `-45deg` | 斜纹 + 虚线 = 非座位区 | 横贯顶部 | 中央 12px 次文字“烫豆操作区 · 不可预约”，`cursor: not-allowed` |
| 店门（底部） | 宽 24 × 高 4，底部居中，无底色，仅双线（上下各 1px `#A8A094`，中间留白 2px）+ 缺口 | 双线缺口 = 门洞 | 缺口宽 12 居中 | 缺口上方 11px 文字“店门” |

桌椅一眼可辨的三重保障：①尺寸（桌 ≥ 18 单位，椅 10×8）；②椅有背条、桌无；③椅有编号 + 状态两行字，桌只有桌名一行字。

### 4.3 椅子四态（颜色只做冗余，主信号 = 边框样式 + 文字）

| 状态 | 边框与底 | 编号行 | 状态牌行（原文模板） | 光标 / 行为 |
|---|---|---|---|---|
| 可订 | 1.5px 实线 `#CFC3AF`，白底 | `#2B2620` | 11px `#4F7A5B`“可订” | `pointer`，悬停仅描边变 `#A8A094`（见 §7） |
| 有人（占用） | 1.5px 点线 `dotted #CFC3AF`，底 `#F7F2E9`（极浅，不算色块） | `#A8A094` | 11px `#A8A094`“有人·至 14:30”（时间为该占用段结束时刻） | `not-allowed`，点击弹 toast，不开详情卡 |
| 规则锁（人数不够 / 分桌限制） | 1.5px 实线 `#E2D9C9`，白底，椅面加 11px 次文字角标“锁”字？不，状态行写规则 | `#A8A094` | 11px `#7A7266`，文案按规则：四人区人数不足写“需 3 位起”；单人 1 位看双人区写“单人区优先”；5–6 人单椅写“需分桌选 2 把”（见 §6） | `not-allowed`，点击 toast 给原因 + 跳转建议 |
| 已选中 | 2px 实线 `#D98CA3`，白底，椅背条同步变 `#D98CA3` | `#2B2620` | 11px `#A34A66`“已选 · 14:30 起 2 小时”（随详情卡实时改） | `pointer`，再点一次不取消（防误触），需详情卡“换椅”或点别椅切换 |

文字牌位置：椅盒下方 4px 独立行，不压椅面，保证缩小后仍可读。占用段结束时间取当天该椅在所选日期的占用并集（见 §8.1）。

## 5. 核心交互

### 5.1 人数选择（滚轮式，强制）

- 形态：iOS 式滚轮，高 180px，可见 5 行，中央高亮行高 36px（14px/700），上下行渐隐（`opacity .45 / .25`，禁用模糊避免性能）。选项原文：`1 位` `2 位` `3 位` `4 位` `5 位` `6 位`。支持鼠标滚轮、触摸滑动、键盘上下键。默认停在 `2 位`（中间值，减少 1 位 / 6 位极端误选），但不算已选——必须手指 / 滚轮动过一次或点选一行，“进入选座”才可用（防默认穿透）。
- 动态规则行（滚轮下方 12px 次文字，随选项实时换）：
  - 1 位：“1 位平时坐单人区；单人区满时可去双人区”
  - 2 位：“2 位可坐单人区或双人区”
  - 3–4 位：“3–4 位全场可订，上大方桌至少 3 位”
  - 5–6 位：“5–6 位需分桌（例 3+2 / 4+2），先选第一把”
- 确认：点“进入选座”→ 弹窗 180ms 收起（曲线见 §7）→ 顶部吸附卡人数回显（例“2 位”）+ toast“已按 2 位筛选可订座位”。之后改人数：点顶部人数回显旁“改人数”文字链 → 重开弹窗（已选座处理见 §8.5）。

### 5.2 日期 + 滑块预览（拖动实时反映全场）

- 日期切换：点日期项 → 该项下划线 160ms 滑入 → 全场椅状态 120ms 内刷新（先换文字牌，后换边框，避免闪色）。同时 toast“已切换到 9 月 11 日，该时段状态已更新”（日期按实际值拼）。
- 时间滑块：`input[type=range]`，min 600（10:00）max 1200（20:00）step 30。拖动时顶部当前值 `throttle 100ms` 更新（例“14:30”），松手后 150ms 内全场重算。拖动中椅子不做位移动画，只换状态（防抖动）。
- 时长步进器：范围 0.5–4 小时，步进 0.5。到达边界时按钮禁用（`disabled` + `#A8A094`），并 toast 边界原因（例“最长可订 4 小时”/“已是最短 30 分钟”）。
- 打烊联动：开始 + 时长 > 20:00 时，时长自动截断到打烊（例 19:00 起最长 1 小时），截断时提示条出现“已按打烊 20:00 截断时长”（见 §8.2）。

### 5.3 点椅聚焦（含动效规格与禁止项）

- 触发：仅“可订”与“已选中”椅可触发。点击 → ①平面图容器 `scrollIntoView({block:'nearest'})` + 内部 `transform: translate` 平移，使目标区域（单 / 双 / 四围框）中心与视口中心对齐；②非目标区域 `opacity .55`（200ms），目标区域保持 1；③详情卡滑出（桌面右列 240ms，移动端底部 260ms）。
- 动效规格：`transform 240ms cubic-bezier(0.2, 0, 0, 1)`；`opacity 200ms linear`。位移上限：桌面 ≤ 120px，移动端 ≤ 80px；若目标已在可视区中央 1/3 内，不位移、只做弱化（避免无意义晃动）。缩放一律不做（`scale: 1`）。
- 明确禁止：①禁止 scale 放大 / 缩小（含 1.02 微放）；②禁止旋转、翻转、抛物线飞入；③禁止全屏遮罩盖住平面图；④禁止自动滚动页面顶 / 底（只平移图内）；⑤禁止聚焦后自动改时间（时间只跟滑块与详情卡步进器）。
- 关闭：点详情卡“关闭”或按 Esc → 详情卡收回（200ms）→ 弱化解除（200ms）→ 焦点回到原椅（`focus()`，键盘用户）。已选椅保持粉描边，不清除。

### 5.4 时间选择形态（推荐：步进器 + 空缺条，不许罗列 20 按钮）

- 推荐形态：详情卡内“开始时间 [-][14:30][+]”+“时长 [-][2小时][+]”两组步进器（步进 30 分钟）+ 下方“当日空缺”横条。
- 为什么不用 20 个按钮：①半小时档 10:00–20:00 共 20 档，平铺在移动端要 3 屏，扫描成本 O(n)；②冲突态混在按钮里，用户要逐个试；③步进器 + 空缺条把“选”与“看”分离：空缺条一眼看全天，步进器精确调，两次点击可达任意档。
- 空缺条规格：宽 100% × 高 28px，圆角 6px，轨道 `#F1EAE0`；已占用段 `#E4D3A8`；当前选中段描边 2px `#2B2620`（非粉，避免与选中椅混淆）；下方 3 个时刻 label（左“10:00”中“14:00”右“20:00”，11px）。点击空缺条空白段 → 开始时间跳到该段起点（30 分钟对齐）；点击占用段 → toast“该段有人（至 14:30），已为你选中最近可订 15:00”（并自动跳到推荐值）。
- 步进器联动：开始 / 时长任一变化 → 空缺条选中段 120ms 平移 → 冲突区实时重算（见 §5.5）。跨打烊自动截断（见 §8.2）。

### 5.5 冲突处理（拦截 + 给出路）

- 判定：所选 [开始, 开始+时长) 与该椅当日占用并集有交集 → 拦截，不允许提交，详情卡冲突区展开（160ms 高度动画）。
- 冲突区三行（固定结构）：①标题 13px/700 `#B3402E`“该时间已有预约”；②正文 13px“该椅 14:00–15:30 有人，你选的 14:30–16:30 与之重叠。”（时间按实际值拼）；③两按钮横排：“换到 15:30”（主，次按钮样式）与“换把椅”（次，文字链，点后收起详情卡并高亮同区可订椅 1.2s）。另附一行小字“或把时长缩到 30 分钟试试”（当缩短可解时才出现，可点）。
- 换时间一键：点“换到 HH:MM”→ 步进器值更新 → 冲突区收起 → toast“已换到 15:30，可以预约”。

### 5.6 填表校验（昵称 + 11 位手机）

- 昵称：占位“例：桃子（2–12 字）”，规则：去首尾空格后长度 2–12，允许中文 / 字母 / 数字，不允许纯空格与 emoji（输入 emoji 即时提示）。错误文案（13px `#B3402E`，输入框下）：“昵称要 2–12 个字”。
- 手机：占位“11 位手机号”，`inputmode="numeric"`，自动截断 11 位，规则 `^1\d{10}$`（1 开头 11 位）。错误文案：“手机号应为 1 开头的 11 位数字”。失焦即校验，输入中错误清除。
- 提交门禁：时间冲突未解 / 昵称错 / 手机错 → 主按钮禁用（底 `#EDE6D8`）。三者全绿按钮才可用。提交中按钮文案变“提交中…”并 `disabled`，防连点（1.5s 内二次点击忽略）。

### 5.7 成功回写

- 成功（网络 200）：①详情卡收起 → ②目标椅状态牌 200ms 内变为“有人·至 HH:MM”（结束时刻 = 开始 + 时长），边框转点线 → ③票据弹层出现（见 §3.5）→ ④顶部“已选 …”更新。失败见 §8.4。
- 票据按钮：“复制票据号”→ toast“票据号已复制”；“返回平面图”→ 票据关闭，焦点回到已订椅（此时为占用态，点击只 toast）。

## 7. 动效与无障碍

### 7.1 统一时长曲线（全站只用 4 档）

| 用途 | 时长 + 曲线 | 说明 |
|---|---|---|
| 微反馈（悬停描边、步进器数字、空缺条选中段） | 120ms `linear` | 无位移，只换色 / 换字 |
| 常规（日期下划线、冲突区展开、toast、椅状态切换） | 160–200ms `cubic-bezier(0.2, 0, 0, 1)`（ease-out 系） | 位移 ≤ 8px |
| 弹层（详情卡滑入、票据、人数弹窗） | 240ms（桌面）/ 260ms（移动端底部）`cubic-bezier(0.2, 0, 0, 1)` | 桌面 X 轴 16px，移动端 Y 轴 24px，透明度 0→1 同步 |
| 聚焦平移（平面图） | 240ms `cubic-bezier(0.2, 0, 0, 1)` | 位移上限见 §5.3，透明度弱化 200ms linear |

### 7.2 各场景动效规格

- 悬停（桌面有鼠标才有）：椅描边 `#CFC3AF`→`#A8A094` 120ms linear，无位移、无阴影、无放大。触摸设备 `@media (hover: none)` 下全部禁用 hover。
- 聚焦：见 §5.3。弱化用 `opacity .55` 200ms linear，不用模糊（`filter: blur` 禁用，性能与可读性）。
- 弹层：详情卡桌面从右 16px 滑入 + 淡入；移动端从底 24px 上滑；票据中央淡入 + 上浮 8px。关闭反向同参。遮罩（仅弹窗 / 票据有）淡入 160ms，无缩放。
- 提示：toast 下 8px 上浮 + 淡入 160ms，停留 2.4s，淡出 160ms。冲突区高度动画 160ms（`grid-template-rows 0fr→1fr` 或 max-height，避免 `height: auto` 跳变）。

### 7.3 无障碍

- `prefers-reduced-motion: reduce`：全部动效 → 0ms（瞬间切换），平移改为直接对齐，toast 仍保留 2.4s 停留但无滑入。JS 侧 `matchMedia` 检测后跳过位移计算。
- 键盘：全流程可达。Tab 序：日期 → 滑块（箭头 ±30 分钟）→ 时长步进 → 椅（S1→S3→D1→D2→Q1→Q4，方向键在图内移动）→ 详情卡表单 → 确认。椅用原生 `<button>`，焦点 2px `#2B2620` outline。Esc 关闭详情卡 / 票据（人数弹窗 Esc 无效）。滚轮选择器支持上下键。
- 读屏：椅 `aria-label` 模板“座位 S2，单人区，可订”/“座位 Q3，四人区，有人至 14 点 30 分”/“座位 Q1，四人区，需 3 位起，规则锁定”。滑块 `aria-valuetext` 例“14 点 30 分”。冲突区 `role="alert"`。toast `aria-live="polite"`。
- 对比度：所有正文 ≥ 4.5:1（见 §2.1）；状态不只靠颜色（边框样式 + 文字双通道）；点线（dotted）+ 文字在灰度打印下仍可区分。

## 8. 边界与异常

1. **单人区满员判定口径**：1 位看双人区是否解锁，唯一口径 = “所选日期 + 所选 [开始, 开始+时长) 内，S1、S2、S3 三把全部有交集占用”。部分占用不算满；时长变化即时重算；占用数据以服务端该日期占用并集为准，前端不缓存跨日期结论。提示条文案（黄底）：“单人区该时段已满，1 位可去双人区选座”。
2. **打烊截断**：营业 10:00–20:00，开始最晚 19:30（保证最小 30 分钟）。开始 + 时长 > 20:00 → 时长自动截断，提示条“已按打烊 20:00 截断时长”+ 时长步进器锁定“+”端。结束恰为 20:00 允许（例 19:00 起 1 小时可订）。
3. **跨天**：日期切换 → 清空已选椅与详情卡输入（时间保留开始 / 时长值），toast“已切换到 M 月 D 日，请重新选椅”。占用、空缺条按新日期重拉，未返回前椅显示骨架态（描边不变、状态行文案“加载中…”12px）。
4. **网络失败**：占用拉取失败 → 椅状态行统一“状态未知，点击重试”（11px `#B3402E`），点击重试该日期；提交失败 → 按钮恢复“确认预约”，toast“网络开小差了，预约未提交，请再试一次”，表单内容保留；连续失败 2 次出现文字链“复制我的填写信息”（拼出“日期 / 时间 / 座位 / 昵称 / 手机”纯文本，方便转人工）。
5. **重选人数后已选座的处理**：点“改人数”重选 → 若新人数下已选椅仍合规（查 §6 矩阵）则保留并 toast“已按 N 位重新筛选，已选座位仍有效”；若变违规（例 2 位选的 Q 椅改成 1 位）→ 已选清除，toast“人数变化，已选座位不符合新规则，请重新选椅”，详情卡关闭、焦点回平面图。5–6 位分桌第一把在改人数后一律清除（时段一致性无法保证）。
6. **并发抢座**：提交返回 409（已被抢）→ 冲突卡模式复用，标题换“慢了一步，该椅刚被订走”，按钮“换到最近可订 HH:MM”/“换把椅”，表单保留。
7. **长时间停留**：页面可见 10 分钟无操作 → 静默重拉占用并 toast“座位状态已更新”（1 次 / 10 分钟上限，避免打扰）。

11. 实现票据与回写：成功后票据号 `PD-` 开头 8 位可复制，已订椅变为“有人·至 HH:MM”点线态。
12. 实现分桌（5–6 位）：第一把确认后按钮变“继续选第二把”，两把时间不一致时被拦截且票据合并两行座位。

14. 过无障碍与动效：开 `prefers-reduced-motion` 后所有位移为 0ms，全键操作走完“选人数→选椅→填表→出票”，对比度抽查 ≥ 4.5:1。

## 10. 待确认问题（需店主拍板，各带推荐）

1. **1 人坐双人桌是否加价 / 限时？** 推荐：不加价但详情卡注明“1 位坐双人桌请尽量 2 小时内”，避免规则复杂化；若要加价，需再加“补差”支付链路（本方案未含支付）。
2. **大方桌“至少 3 位”是否允许 2 位拼桌（与其他客拼）？** 推荐：不允许拼桌（手工拼豆需整桌安静），保持“2 位锁 Q 区”；若允许，Q 区对 2 位改为“可点但提示可能拼桌”，文案需你定。
3. **超时释放按 15 分钟还是 30 分钟？** 推荐：15 分钟（票据文案已按 15 分钟写），周末可人工延长；若要 30 分钟，票据小字与占用释放逻辑同步改一处。
4. **5–6 位分桌是否必须同区域相邻？** 推荐：不强制相邻、只要求同时段（本方案已实现），强制相邻会大幅降低订成率；若坚持相邻，需定义“相邻”= 同区两椅，并加校验。
5. **是否要“等候名单”（满座时留电话排队）？** 推荐：一期不做，先跑“有人·至 HH:MM + 换时间”自助分流；若要做，二期在占用态详情卡加“满座提醒”按钮（本期预留按钮位，不实现）。
